# Use AGENTS.md as the discovery surface

## Status
Accepted

## Context
A new root `CONTEXT.md` would compete with AGENTS.md (AAIF / Linux Foundation).

## Decision
Ship Context Pack as an AGENTS.md companion under `.context/`, with POLICY.md as the router.

## Consequences
- No rival always-on instruction file
- Adapters stay thin pointers
- Progressive retrieval is explicit in POLICY.md

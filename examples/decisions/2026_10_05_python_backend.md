# Use Python for backend scripts

**Date:** 2026-10-05
**Status:** Accepted

## Context
Need to build internal tools and automation scripts for the project.

## Decision
Use Python for all backend scripts and internal tooling.

## Rationale
- Team expertise in Python
- Good ecosystem for CLI tools
- Easy to maintain and extend

## Consequences
- Developers need Python 3.11+
- Potential dependency management overhead
